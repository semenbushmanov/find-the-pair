# Game "Find the Pair"

The goal of the game is to find all the pairs of tiles.

## Features

- 4×4 board (16 tiles)
- 8 pairs of matching colors
- "Play again" button
- Win condition when all pairs are found

## Technologies

- React
- Tailwind CSS
- Vite

## Build production version

```bash
npm run build
```
## Launch development version

```bash
npm run dev
```
